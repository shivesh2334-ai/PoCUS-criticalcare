# PoCUS in the Critically Ill

A practical, evidence-linked learning application for clinicians using point-of-care ultrasound in critical illness.

## Learning domains

- Shock phenotyping
- LVOT VTI and haemodynamics
- Fluid responsiveness
- Lung ultrasound
- Systemic venous congestion and VExUS
- Practical video skills and curated guidelines

## Deployment

This is a zero-build static application. Vercel serves `index.html` directly from the repository root.

## Important

For clinician education only. It does not replace supervised competency assessment, local protocols, formal echocardiography, or patient-specific clinical judgement.
